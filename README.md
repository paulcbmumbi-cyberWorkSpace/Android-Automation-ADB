# Android-Automation-ADB

This project contains small Python utilities for Android device setup and device tracking using ADB.

## Included scripts

### 1) auto-adb.py
Automates common Android setup tasks for connected devices.

Features:
- Detects the `adb` executable from the system `PATH`
- Enables USB debugging on the connected device
- Opens Android Settings on the device
- Pushes files from a local folder to the device
- Installs APK files from a local folder or a single APK

Default behavior:
- Reads files from an `APK/` folder beside the script
- Copies them to `/sdcard/APK`
- Skips files that already exist on the device
- Installs every `.apk` file found in the source directory

Run it:

```powershell
python auto-adb.py
```

### 2) collect-device-info.py
Collects authorized Android device information and saves it to an Excel workbook.

Features:
- Checks which devices are connected and authorized through ADB
- Reads each device model name using `getprop ro.product.model`
- Prompts for a satellite name for each device
- Appends collected records to `device_info.xlsx`

Run it:

```powershell
python collect-device-info.py
```

The script creates or updates a workbook named `device_info.xlsx` in the project folder.

## Requirements

- Python 3.8+
- Android SDK Platform Tools installed and `adb` available in `PATH`
- A connected Android device with USB debugging authorized
- For the Excel script, `openpyxl` installed in the Python environment

Install the Excel dependency if needed:

```powershell
pip install openpyxl
```

## Notes

- `auto-adb.py` exits cleanly if `adb` is missing from `PATH`.
- The script uses `adb install` for APK installation.
- `collect-device-info.py` only includes devices reported by `adb devices` as `device`.
- Existing workbook records are preserved and new device serial numbers are appended only once.

## Customization

If you want to use a different local folder or device path, update the function arguments in the script or call the functions directly from another Python module.
